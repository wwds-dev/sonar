# Support

SONAR is free software provided as is (see [LICENSE](LICENSE)), maintained by one person in
their spare time. There is no paid support and no guaranteed response time.

## Where to ask

| You want | Go to |
|---|---|
| Help running it, or a question about what a number means | the in-app **Learn** tab first (the manual and glossary), then a [GitHub issue](https://github.com/wwds-dev/sonar/issues) |
| To report a bug | a GitHub issue: version (window title), macOS version, what you did, what you expected. Do not paste API keys or the contents of `.env` |
| To report a security problem | [SECURITY.md](SECURITY.md), privately |
| To suggest a feature | a GitHub issue; see `SUGGESTIONS.md` for what is already considered |

## What to expect

Issues are read **about once a week**; a reply within 7 days is the target, not a promise.
Fixes land when the maintainer has time.

## What SONAR is not

It is not financial, investment or betting advice, it trades on paper only, and its own
research finds no edge. Nobody here can help you with a real-money decision.

## Known limits

- macOS only (developed on Apple Silicon); no binary download, run from source.
- Free data sources (Yahoo, ESPN, Nasdaq, news feeds) change without notice; a broken feed is
  the most common fault. The Wire and Screener tabs say when a source is stale.
